# Dashboard Statistik Deskriptif (Streamlit)

- `streamlit_app.py`  : dashboard statistik deskriptif (data latihan 1, bisa upload CSV/Excel)
- `streamlit_2var.py` : statistik 2 variabel + korelasi, regresi, dan prediksi
- `data/data1.csv`    : data latihan 1

Jalankan lokal: `pip install -r requirements.txt` lalu `streamlit run streamlit_app.py`
